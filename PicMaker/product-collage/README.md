# 상품 이미지 콜라주 v1.13

Windows용 사진 누끼 제거·리사이즈·콜라주 편집 프로그램입니다.

## 실행

1. Python 3.11 이상을 설치합니다. 설치 시 **Add Python to PATH**를 선택합니다.
2. 이 프로젝트를 내려받아 압축을 풉니다.
3. `run.bat`을 실행합니다. 첫 실행 시 필요한 라이브러리를 설치합니다.
4. **이미지 추가** 또는 **폴더 추가**로 사진을 넣습니다.

## 기능

- 파일 추가 및 드래그앤드롭
- 자동 배경 제거 및 상품 크기 통일
- 수동 브러시 지우기·복원, Undo/Redo
- 콜라주 미리보기와 드래그 위치 이동
- 핸들·마우스휠 크기 조절
- PNG/JPG 저장

썸네일 다운로드, URL 수집, 사이트 규칙, 원격 업데이트 기능은 제거했습니다.
자동 누끼용 모델은 최초 사용 시 인터넷으로 내려받을 수 있습니다.
원본 파일은 별도로 보관하고 결과를 확인한 뒤 사용하세요.

## 파일

- `app.py`: 프로그램 소스
- `requirements.txt`: 의존 라이브러리
- `run.bat`: 설치 및 실행
- `build_exe.bat`, `build_exe_onefile.bat`: Windows 실행 파일 빌드
- `README.txt`: v1.13 변경 및 검증 기록

## 검증 범위

파일 추가 후 자동 처리와 위치·크기를 반영한 저장 픽셀 비교를 확인했습니다.
누끼·브러시 보정 코드는 이전 버전과 동일함을 확인했습니다.
v1.13 GUI 재실행은 작업 환경의 Tcl/Tk 문제로 검증하지 못했습니다.

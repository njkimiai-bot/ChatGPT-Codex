상품 이미지 누끼 · 리사이즈 · 콜라주 ver1.13

실행: 새 폴더에 압축을 풀고 run.bat 실행.
이미지 추가, 폴더 추가 또는 파일 드래그앤드롭으로 사진을 넣으세요.

유지 기능:
자동 누끼 및 크기 통일, 수동 브러시 보정, Undo/Redo,
콜라주 미리보기, 드래그 위치 이동, 핸들/마우스휠 크기 조절, 이미지 저장.
보정 결과 저장 폴더는 배경제거 보정 탭에서 선택할 수 있습니다.

제거 기능:
모든 URL/썸네일 다운로드, 원클릭 웹 자동화, 색상 URL 수집,
사이트 규칙 편집 및 원격 업데이트, 관련 설정 파일 및 전용 의존성.
화면 탭은 이미지 목록 / 배경제거 보정 두 개입니다.

검증:
삭제된 코드 참조 검사, 기존 누끼/브러시/보정 미리보기 코드 동일성 검사,
파일 추가 후 자동 크기 통일 및 위치/크기를 반영한 저장 픽셀 비교 통과.
현재 테스트 환경의 Tcl/Tk 파일 접근 문제로 GUI 재실행 검증은 하지 못했습니다.

자동 누끼용 rembg는 유지하므로 최초 모델 준비 시 인터넷이 필요할 수 있습니다.
